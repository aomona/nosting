# NIP-05

[NIP-05](https://github.com/nostr-protocol/nips/blob/master/05.md) の識別子をプロフィールで表示・編集し、検索欄で解決します。「公開鍵と一致」は well-known の `names` とプロフィール公開鍵の対応だけを表し、本人の信頼性を保証するバッジではありません。取得失敗・不一致は「未確認」と表示します。

- ブラウザから固定 HTTPS well-known パスへ直接 GET。リダイレクト禁止、資格情報・referrer なし、5 秒タイムアウト、128 KiB 上限。
- ローカル部は小文字 `a-z0-9-_.`、ドメインは ASCII DNS / punycode。IP リテラル、ローカル向けホスト名、ポート、認証情報、パス・クエリの混入を拒否します。Unicode ドメインは punycode で入力してください。DNS 解決先の IP 判定を行うサーバープロキシはありません。
- 256 件のメモリキャッシュ。成功は 5 分、失敗は 30 秒。プロフィール表示は 5 分ごとに再確認。キャンセルをキャッシュしません。
- 検索は明示的な送信時のみ。well-known の公開鍵について、設定済み読み取りリレーの署名済み最新 kind 0 を取得し、`nip05` の逆参照も照合します。リレーごとに 8 秒・30 イベント上限を設け、部分障害を表示します。設定済みリレーにプロフィールがない場合は未確認になります。well-known の任意 `relays` ヒントは自動利用しません。
- 検索結果から既存の公開鍵プロフィールへ遷移します。フォローの正本は従来どおり公開鍵です。クエリ・画面・アカウント・リレー変更で古い検索を破棄します。
- 編集は既存の最新イベント再確認、署名前後の競合・アカウント・キャンセル検知を維持します。未編集フィールドや未知フィールド・タグは保持し、空欄の NIP-05 は削除します。編集時にリレー障害がある場合は安全のため保存を止めます。

CORS・接続障害・タイムアウトで確認できない場合があり、不正な本人だとは断定しません。読み取れなかったリレーの更新や、確認後の DNS / メタデータ変更まで保証しません。

## 検証

`npm test` はリゾルバー、偽造署名、最新イベント・同時刻、逆参照不一致、部分障害、キャンセル、キャッシュ・サイズ制限、および既存のプロフィール編集・フォロー処理を検証します。

```sh
node tests/browser/server.mjs
python tests/browser/nip05.py
```

ブラウザ検証は実際の M3E コンポーネントとローカルの HTTP/WebSocket/署名モックを使います。公開リレーへの接続・投稿はありません。1280 / 390 / 320px の表示、検索、編集、公開鍵遷移、未確認表示、横はみ出しを確認し、画像は `/tmp/nosting-nip05-*.png` に出力します。画像やテスト秘密鍵はリポジトリに保存しません。
