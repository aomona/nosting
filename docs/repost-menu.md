# リポストメニュー

リポストボタンは M3E の `Menu` / `MenuItem` を開きます。表示は「リポスト」と「引用する」の2項目だけで、コンテナー、アイコン、角丸、色、フォーカス表示、開閉の動きは既存の M3E に従います。ネイティブ popover の top layer と M3E の位置補正を使うため、投稿カードの高さを変えずに表示できます。

- Enter / Space / 矢印で開き、矢印 / Home / End で項目移動、Enter / Space で選択。Escape は起点ボタンへ戻り、Tab・外側クリック・ページスクロールで閉じます。
- 非同期処理中も項目のフォーカスを維持し、`aria-disabled` と処理ロックで重複選択を防ぎます。閉じた後にログインが完了しても引用コンポーザーを開きません。リポストの署名待ち中に閉じた場合は、遅れて返る署名を送信しません。送信開始後のイベントを取り消す機能ではありません。
- 未ログインで「リポスト」を選ぶと従来どおりログインのみ行います。ログイン後に再度選択すると送信します。「引用する」はログイン後に既存コンポーザーを開きます。拡張機能がなければ既存のログイン画面を表示します。
- `findRepostSource` / `repostPayload`、kind 6 の内容とタグ、署名検証、書き込みリレー選択、ACK 処理、引用コンポーザーの下書きと再送処理は維持しています。

main の引用コンポーザー、宛先リレー配信、アカウント別ブックマーク、DM を維持します。main に入った #34 の削除要求は投稿ヘッダーの「投稿の操作」メニューに残し、小型リポストメニューと併存させます。自分のリポストの削除要求は元投稿を削除せず、kind 5 の e / k タグ・署名確認・ACK・削除済み表示とフォーカス復帰も既存実装を使います。

## 検証

```sh
npm ci
npm run check
npm run lint
node tests/browser/server.mjs
# 別ターミナル。Python Playwright と Chromium が必要です。
python tests/browser/repost-menu.py
python tests/browser/quote-post.py
python tests/browser/repost-deletion.py
```

ブラウザテストは実際の App と M3E を使用し、署名済み合成投稿・架空プロフィール・一時生成鍵・mock WebSocket のみを使います。外部 HTTP は遮断し、公開リレーへの送信はありません。1280×900、390×844、320×640 でキーボード、フォーカス復帰、外側クリック、四隅の位置補正、スクロール、連打、投稿カードへのクリック伝播、ログイン前後、署名拒否・待機中止、kind 6 と送信先、引用への移行を検証します。スマホ幅では touch 入力も使用します。四隅の位置検査に限り、テストが起点ボタンを一時移動します。

Chromium の `Locator.click()` はスクロール位置によって native popover 内の要素を文書へ強制スクロールするため、メニュー選択は表示範囲を検査してから実座標の mouse / touch 入力で行います。キーボードでの選択も別に検査します。実機 iOS / Safari は対象外です。

`repost-deletion.py` は PC / スマホで両メニューの併存、未ログイン・他人の投稿の削除不可、自分のリポストと投稿の削除要求、元投稿の維持、署名拒否・再試行、重複送信防止、キャンセルと削除済み行へのフォーカス復帰を同じ mock で検証します。

スクリーンショットは `/tmp/nosting-repost-{1280,390,320}-dark.png` に保存します。画像は外部アップロードせず、リポジトリにも含めません。
